# Images to add

The site renders fine without these (each `<img>` has an `onerror` handler
that hides broken images), but to get the full visual you should drop the
files below into the matching paths.

## Lab banner (home page)

- `banner.jpg` — a wide group/landscape shot (Pantanal, Cerrado, pond,
  fieldwork). Recommended ~1600×600 px (will be cropped to a max height of
  380 px on the home page).
